# ترقية وكيل Wakeel — 10 أكتوبر 2026

هذه النسخة تطور المحرك الموجود في المشروع؛ لا تدّعي أنها نسخة مطابقة من Manus أو أي خدمة تجارية مغلقة. الهدف هو جعل Wakeel أكثر استقلالية مع البقاء ضمن حصص الخدمات المجانية وعدم إضافة مزود مدفوع كخطة احتياطية.

## ما تغيّر

- **محرك تخطيط تكيفي:** بعد خطوة بحث أو قراءة أو تحليل ناجحة في المهام غير البسيطة، يمكن للمتحكم مراجعة الجزء المتبقي من الخطة مرة واحدة. يمكنه الإبقاء عليها أو استبدال الخطوات غير المنفذة فقط، مع إزالة تكرار الإجراءات المكتملة والحفاظ على خطوة تجميع نهائية. إصلاحات فشل الأدوات ما زالت محدودة.
- **بحث متعدد المصادر:** أضيفت أداة `web_research` التي تبحث ثم تحاول قراءة مصدرين مستقلين افتراضياً (حتى ثلاثة). تعاد روابط المصادر التي تمت قراءتها فعلياً إلى المحرك لتستخدم عند كتابة الإجابة النهائية.
- **بحث لا يعتمد دائماً على المتصفح:** يحاول `web_search` أولاً قراءة صفحة DuckDuckGo العامة مباشرة دون مفتاح API أو دقائق متصفح، ثم يستخدم Cloudflare Browser Run إذا لم يرجع البحث المباشر نتائج قابلة للاستخدام.
- **إجابات موثقة:** أصبحت مرحلة الإجابة النهائية تطلب الاستشهاد بالمصادر المتاحة، وشرح نقص الأدلة أو اختلافها، والالتزام بلغة المستخدم. وتضاف قائمة بالمصادر في نهاية النتيجة.
- **نماذج أحدث ضمن الطبقات المجانية:** يستخدم Groq نموذج `openai/gpt-oss-20b` بدلاً من Llama 3.1 8B المتوقف، ويستخدم OpenRouter متغيرات `:free` فقط. كما يجرب Workers AI النماذج المجانية الموثقة: GLM-4.7-Flash ثم Gemma 4 26B A4B ثم Nemotron 3 120B A12B.
- **تحقق أفضل من المدخلات:** تمت إضافة فحوصات لمدخلات أدوات البحث والقراءة وكتابة الملفات، مع رفض روابط القراءة المحلية أو الخاصة، وإضافة حدود زمنية لطلبات مزودي الذكاء الاصطناعي.
- **اختبارات جديدة:** اختبارات تدوير نماذج Workers AI، وتحليل نتائج DuckDuckGo، والتخطيط التكيفي.

## خدمات مجانية وإعدادها

1. سجّل الدخول إلى حساب Cloudflare مجاني، ثم نفّذ `npx wrangler login` وأنشئ قاعدة D1 حسب تعليمات README.
2. لا تحتاج Workers AI إلى مفتاح مزود مستقل؛ يستخدم الربط `AI` الموجود في `wrangler.toml`.
3. اختيارياً، أضف مفتاح Groq Free أو OpenRouter Free لزيادة فرص توفر النموذج. في OpenRouter تُستخدم معرفات تنتهي بـ `:free` فقط. اترك بيانات الدفع وإضافة الرصيد غير مفعّلة.
4. شغّل `npm ci` ثم `npm run typecheck` و`npm test` قبل النشر. وللواجهة شغّل `npm --prefix web ci` ثم `npm run web:build`.

**تنبيه مهم:** لا تضمن أي مكتبة برمجية أن كل خدمة خارجية لن تطلب تحققاً إضافياً عند التسجيل؛ فقد تختلف سياسات التسجيل ومكافحة الإساءة حسب البلد والحساب. هذا المشروع لا يتحايل على تلك الفحوصات. كذلك، الحصص المجانية محدودة وقد تتوقف مؤقتاً عند نفادها. أبقِ حساب Cloudflare على الخطة المجانية، ولا تستخدم حساب مزود ربطت به وسيلة دفع إذا كان شرطك عدم تحمل أي تكلفة.
